# 삼삼백과 개인정보처리방침 초안

시행일: 2026년 7월 21일

삼삼백과는 인삼 사진 기반 AI 판독, 인삼 시세, 백과, 지도 정보를 제공하는 앱입니다. 본 문서는 Google Play 등록과 사용자 안내를 위한 개인정보처리방침 초안입니다. 실제 공개 전 운영 주체의 상호, 연락처, 보관 기간, 서버 운영 정책을 확인해 확정해야 합니다.

## 1. 처리하는 정보

삼삼백과는 서비스 제공을 위해 다음 정보를 처리할 수 있습니다.

- 사용자가 촬영하거나 선택한 인삼 사진
- AI 판독 결과: 연근, 등급, 신뢰도, 가격 등급 코드 등
- 앱 내 저장 목록: 사용자가 저장한 판독 결과와 이미지 경로
- 관리자 기능 사용 시 관리자 ID 및 인증 토큰

일반 사용자를 위한 소셜 로그인 또는 회원가입 기능은 사용하지 않습니다.

## 2. 정보 이용 목적

처리되는 정보는 다음 목적에 사용됩니다.

- 인삼 사진 AI 판독
- 판독 결과 화면 표시
- 사용자가 저장한 판독 이력 표시
- 지도 데이터 CSV 반영을 위한 관리자 인증
- 서비스 오류 확인 및 품질 개선

## 3. 사진 데이터 처리

사용자가 AI 판독을 실행하면 사진 또는 선택한 이미지 영역이 서버로 전송되어 AI 판독에 사용됩니다. 서버는 기본적으로 원본 사진을 영구 저장하지 않는 것을 원칙으로 합니다.

앱에 저장한 판독 목록은 사용 중인 기기 내부에 저장됩니다.

## 4. 제3자 제공

삼삼백과는 사용자의 개인정보를 법령에 따른 경우를 제외하고 제3자에게 판매하거나 제공하지 않습니다.

## 5. 보관 및 삭제

앱 내부에 저장된 판독 결과는 사용자가 앱에서 삭제할 수 있습니다. 서버 로그와 관리자 처리 기록의 보관 기간은 실제 운영 정책에 따라 확정해야 합니다.

## 6. 권한 안내

앱은 다음 권한을 사용할 수 있습니다.

- 카메라: 인삼 사진 촬영
- 사진/이미지 접근: 사용자가 선택한 사진으로 AI 판독
- 인터넷: 서버 AI 판독, 시세, 백과, 지도 데이터 조회

## 7. 보안

운영 배포 전 사진 데이터 전송 구간에 HTTPS를 적용하는 것을 권장합니다.
